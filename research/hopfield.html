In disordered neural networks, finite is different

Birth of sequential memory recall in finite delayed Hopfield networks

University of Chicago
March – August 2026Supervisor
Vincenzo Vitelli · James Franck InstituteManuscript in preparation
Working manuscript · PDF ↗Internship report · PDF ↗Code, data & examples · GitHub ↗

The system

Symmetric couplings store memories. A delayed non-reciprocal drive orders them into a sequence. Finite disorder decides when the network stops being pinned and starts to move.

The result

Every memory ends at its own saddle-node threshold, forming a central-limit-like, near-Gaussian ensemble whose variance vanishes as the system size grows. The bulk destroys static recall, while the extreme value identifies the sequence bottleneck and predicts the dynamical onset of an invariant cycle.

The method

An exact finite-sample reduction makes every memory branch accessible. Continuation, delay integration, Floquet spectra, Lyapunov analysis and finite-size statistics test the mechanism from independent directions.

THE CENTRAL QUESTION

How is sequential memory recall born from static pattern retrieval in associative memory neural networks?

Methods

  • Exact low-rank dimensional reduction
  • Continuation and stability analysis
  • Delay-differential equations
  • Seed-resolved validation and finite-size scaling
